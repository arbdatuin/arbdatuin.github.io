# Publishing Version 5

1. Extract this ZIP and upload its contents to the root of `arbdatuin/arbdatuin.github.io` on `main`. Preserve folder paths.
2. If upgrading from V4, explicitly delete `experience.html` and `resume.html` from GitHub. Uploading a ZIP replacement does not delete old files.
3. If you published the profile README separately, replace it with the revised `PROFILE-README.md` (rename to `README.md` in the profile repository).
4. In Settings → Pages, select Deploy from a branch → main → / (root).
5. Check homepage, skills and eight case studies after deployment.
